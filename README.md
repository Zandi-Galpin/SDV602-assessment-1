# SDV602-assessment-1
Legendary Goose Assassin 2026, a text adventure type game in which you play as a goose which goes on a quest to find The Golden Peas (a pile of golden peas). The goose goes from area to area, fighting enemies at certain set locations, getting items, consumables and gold as rewards. 

# Setup
1. Clone the repo
2. Create a venv: `python -m venv venv`
3. Activate it: `venv\Scripts\activate` (Windows) or `source venv/bin/activate` (Mac/Linux)
4. Install dependencies: `pip install -r requirements.txt`

# Running it
- GUI mode: `python refactored.py`
- Headless test mode: `python refactored.py --headless`
